## Mods

### [Create: Mob Grinding](https://github.com/Manny-Minecraft/CreateMobGrinding)

<a href="https://www.curseforge.com/minecraft/mc-mods/create-mob-grinding"><img src="https://img.shields.io/curseforge/dt/1557641?logo=curseforge&label=&suffix=%20&style=flat&color=242629&labelColor=F16436&logoColor=1C1C1C" alt="CurseForge"></a>
<a href="https://modrinth.com/mod/create-mob-grinding"><img src="https://img.shields.io/modrinth/dt/create-mob-grinding?logo=modrinth&label=&suffix=%20&style=flat&color=242629&labelColor=5CA424&logoColor=1C1C1C" alt="Modrinth"></a>

An addon for **Create** that turns mob farming into kinetic machinery. Extract souls from vanilla spawners, spawn mobs with rotational power and grind them with upgradable, enchantable blades.

### [Productive Cows](https://github.com/Manny-Minecraft/Productive-Cows)

<a href="https://www.curseforge.com/minecraft/mc-mods/productive-cows"><img src="https://img.shields.io/curseforge/dt/1554716?logo=curseforge&label=&suffix=%20&style=flat&color=242629&labelColor=F16436&logoColor=1C1C1C" alt="CurseForge"></a>

A data-driven resource mod: breed Material Cows, milk molten resources and cool them into ingots. Supports Create, Mekanism and the Thermal Series, and new cows can be added with datapacks or KubeJS.

## Tools

### [ModSmith](https://github.com/Manny-Minecraft/ModSmith)

A Claude Code skill for Minecraft mod development: from an idea to a playable mod, code audits, fixes, crash logs and ports between versions and loaders, with a focus on good engineering practices.

## Contributing

Contributions are welcome! Every repository has issues labeled [`good first issue`](https://github.com/search?q=org%3AManny-Minecraft+label%3A%22good+first+issue%22+state%3Aopen&type=issues) and `help wanted`, such as translations and compatibility with other mods.

Found a bug or have an idea? Open an issue in the mod's repository: the forms will guide you through what we need.
